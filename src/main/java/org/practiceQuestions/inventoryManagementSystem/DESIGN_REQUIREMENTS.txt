Design Inventory Management System

System to track, manage and optimize product inventory within a business.
System handles multiple products, tracks stock levels, process orders and ensure replenishment.

Key Features:
1. Should support multiple product types.
2. inventory operations like add, remove, transfer etc.,
3. Real Time alerts for low stock.
4. Generate inventory reports.


Setup:
1. multiple warehouses store different product types.
2. products can be added, transferred between warehouses, and removed when sold or discarded.
3. Each Product has attributes like SKU, name, quantity, price, and supplier information.
4. System should provide real-time alerts when stock levels fall below a certain threshold.


Different Products - Factory Pattern - easy addition of new product types without modifying existing code
Inventory Manager - Singleton Pattern for single point of control, consistent state management across the system
Warehouse - Composite Pattern (to manage multiple warehouses)
Alerts - Observer Pattern (to notify when stock levels are low)
Replenishment Strategy - Strategy Pattern (to allow different replenishment strategies based on product type or demand)
